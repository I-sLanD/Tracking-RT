# DeepSORT C++ 初步验证

验证通过：原生 YOLO26 → OSNet x0.25 → DeepSORT。

- 公共视频：OpenCV vtest.avi，前 180 帧，10 FPS，连续帧不跳帧。
- C++ 算法测试通过；115 帧受控序列与作者 Python 实现逐帧对照，ID、状态和生命周期一致。
- Kalman mean 最大误差 2.22e-16，covariance 最大误差 2.27e-13。
- 公共视频的 CPU 和 GPU 缓存分别与作者 DeepSORT 对照，轨迹关联、状态、生命周期一致。新建轨迹编号排序可能不同，验证仅在出生帧绑定编号对应关系，之后禁止重映射。
- CPU/GPU 检测框最大差 0.0001221 px，ReID 特征最小余弦相似度 0.999999881，轨迹关联一致。
- 两个模型的 ORT profile 均确认 DirectML 节点执行；可能包含少量 CPU 节点，事件数量不表示耗时比例。

| 阶段（ms） | CPU 均值 | DirectML 均值 | DirectML P95 |

每帧平均行人数 6.02，峰值 12；ReID 使用固定 batch=1，逐人推理。
计时排除模型初始化、暖机、PNG 解码、结果日志、视频解码和渲染；不是摄像头端到端 FPS。

## 验证边界

受控交叉/漏检验证只证明实现行为。公开视频无真实 ID 标注，不能据此声称 IDF1、HOTA、MOTA 改善或复杂遮挡效果。
当前仅跟踪 COCO person；OSNet 是行人 ReID 模型。固定 dt=1，max_age 按帧计；尚未实现真实时间间隔预测、相机运动补偿、实时视频采集或 Jetson TensorRT。

## 后续深化
